# Быки и коровы 🐂🐄

Андроид-игра: угадайте 4-значное число. Полный проект с автосборкой APK на GitHub Actions и релизной подписью.

---

## Часть 1. Загрузка проекта на GitHub

1. Зарегистрируйтесь на https://github.com (если аккаунта ещё нет).
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Имя: `BullsAndCows`, вид: **Public** (или Private — Actions работает и так), галочку README НЕ ставьте.
4. Нажмите **Create repository**.
5. На странице репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
6. **Важно про скрытую папку `.github`:** она начинается с точки, поэтому в проводнике Windows может быть невидима. Включите **Вид → Показать → Скрытые элементы**. Перетаскивайте папки целиком — тогда `.github` уедет вместе со всеми.
7. Дождитесь загрузки и нажмите **Commit changes**.

## Часть 2. Сборка APK (debug или release)

1. Откройте вкладку **Actions** вверху репозитория.
2. Слева выберите **«Сборка APK»**.
3. Нажмите **Run workflow → Run workflow**.
4. Подождите 3–5 минут, появится зелёная галочка.
5. Откройте запуск, внизу блок **Artifacts** → скачайте `BullsAndCows-apk` → распакуйте.
6. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

**Debug или release?** Если ключ подписи ещё не создан — соберётся `app-debug.apk`. После создания ключа (см. Часть 3) тот же workflow начнёт собирать `app-release.apk`.

## Часть 3. РЕЛИЗНАЯ СБОРКА (по шагам)

### Шаг 3.1. Добавьте секрет с паролем

1. В репозитории: **Settings → Secrets and variables → Actions**.
2. Нажмите **New repository secret**.
3. **Name:** `KEYSTORE_PASSWORD`
4. **Secret:** придумайте пароль (латиница + цифры) и вставьте.
5. **Add secret**.

⚠️ **ЗАПИШИТЕ ПАРОЛЬ в надёжное место!** Без него нельзя выпускать обновления: магазин не примет APK, подписанный другим ключом.

### Шаг 3.2. Создайте ключ подписи

1. Вкладка **Actions** → слева выберите **«Создать ключ подписи»**.
2. Справа **Run workflow → Run workflow**.
3. Через ~1 минуту workflow сгенерирует ключ и **сам закоммитит** его в репозиторий: появится папка `keystore/` с файлом `app-release.keystore`.
4. После этого сборка «Сборка APK» начнёт выпускать **`app-release.apk`** автоматически.

### Шаг 3.3. Скачайте release-APK

1. «Сборка APK» → дождитесь зелёной галочки → скачайте артефакт.
2. Внутри должен быть именно **`app-release.apk`** (не `app-debug.apk` — это признак успеха).
3. Если на телефоне стояла старая debug-версия — **сначала удалите её**: подписи разные, установка поверх не пройдёт.
4. Установите `app-release.apk`.

### Как это работает технически

- `app/build.gradle` проверяет наличие `keystore/app-release.keystore` в репозитории. Ключ есть → сборка подписывается им и становится release. Ключа нет → обычный debug.
- Пароль хранится только в секретах GitHub, в коде его нет.

### Частые проблемы

| Проблема | Решение |
|---|---|
| Красный крест у «Создать ключ подписи» | Проверьте, что секрет `KEYSTORE_PASSWORD` создан (Шаг 3.1). Пришлите лог — разберём |
| Скачался `app-debug.apk` | Папки `keystore/` нет в репозитории — повторите Шаг 3.2 |
| «Приложение не установлено» на телефоне | Удалите старую debug-версию и ставьте заново |
| Не вижу папку `.github` при распаковке | Включите в проводнике «Скрытые элементы» |

## Часть 4. Обновления игры

1. Внесите правки в код.
2. В `app/build.gradle` **увеличьте `versionCode`** (1 → 2 → 3…) и при желании `versionName`.
3. Commit → push → Actions соберёт новый release-APK.

## Часть 5. Публикация в RuStore (обзор)

1. Аккаунт разработчика: rustore.ru/developer → вход через VK ID → фото паспорта и селфи.
2. Загрузите `app-release.apk` (debug не примут).
3. Заполните карточку: название, описание, иконка, скриншоты, категория.
4. Модерация: от пары часов до пары дней.
5. Монетизация: встроенные покупки — только ИП/юрлицам; **реклама (Yandex Mobile Ads) доступна физлицам** — можно встроить баннер или «рекламу за награду» (посмотрел ролик → получил подсказку в игре).
